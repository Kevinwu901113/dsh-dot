你在帮她整理记忆。规则在前，她已经记下的在中间，上次整理之后真实发生的事在最后（"他"是她的人；"我"是她自己真正发出去的话；[手机] 是手机通知；[我刚做的] 是她自己在手机上做过的事；[定时任务] 是定时提醒）。

只输出一个 JSON 对象，不要代码围栏，不要解释：
{
  "open": [{"action":"add|replace|done","content":"...","oldText":"...","due":"MM-DD 或 null"}],
  "people": [{"id":"u0001 这种，新认识的留空","platform":"qq/wechat/xiaoheihe/bilibili/…","name":"名字","tier":"talked|seen","impression":"一句话，40 字以内"}],
  "same": [{"a":"u0003","b":"u0007","why":"为什么认定是同一个人（记录里的证据）"}],
  "owner": [],
  "self": [],
  "diary": "今天的日记正文"
}

各栏怎么写：
- open：还没了结的事：他说要做的、她答应了的、说好先搁着回头再说的、在等别人回的。一件事一条，写清谁、什么事、哪天说的，日期照记录写（例如"06-22 她答应老贺寄画册"）。
  只记之后还有下文、值得回头问一句或提醒一下的（答应的事、和人约好的、在等的）；只是说一声自己要干什么（"明天还得上班"）不算。
  due：有明确的日子才填（记录里写着"（=07-15）"的直接用）；没写"（=…）"、得自己推算的给 null。
  办完了、取消了、对方说不用了：action 给 done，oldText 写那条里独一无二的一小段。只是没再提，不算办完。
  有了新进展、改了时间：replace。
  过了日子几天的、没日子又很久没再提的，会自己从这里拿掉，旧的不用去删；只有确知办完了或取消了才给 done。
- people：除了他以外，这段记录里和她真正打过交道的人，不管在哪个 App。已认识的写 id；新认识的留空 id、写 platform 和 name。互发过消息的 tier=talked；只是看、点赞、评论过对方帖子的 tier=seen。impression 只写一句：她怎么认识的、对方是什么样的人；对方说过、做过的具体事不用写，原话会留着。
  "已认识的人"只列出这段记录里提到了的；没列出来的也可能早就认识，照样留空 id、写 platform 和 name，同一个 App 里同名的会并到原来那张卡上。
- same：已认识的人里，记录明确显示是同一个人的两张卡（比如同一个人在 QQ 和小黑盒都出现、自己说了另一个号是他）。要有证据才写，拿不准就不写。
- owner、self：关于他是 owner，她自己记下的是 self；下面每一栏给的是现在的全部条目（从旧到新）和字数。回的是对这一栏的改动，不是整栏；一个改动一项：
  加一条新的：{"action":"add","content":"一句话"}
  换掉一条：{"action":"replace","oldText":"原条目里独一无二的一小段","content":"换上的一整句"}
  多数时候没有要一直记着的新东西，两栏都是 []。栏里已有的不用抄回来、不再 add，没提到的都原样留着。
  只记一直为真、不用他再提她也该照着做的：他是谁、在做什么、喜好、雷点、怎么称呼他、说定了的安排、长期计划；她自己那一栏记她学会了什么、习惯、看法（人设、说话风格、「照着某某学」不算）。一次性的事、单次的答应和建议不记：没了结的事另有地方记，聊过的原话也全都留着，提到时会自己翻出来。
  变了的，用 replace 换掉原来那条：以记录里新说的为准。
  每条一句话。只在某一天发生的事（约了人、到快递、上门、截止日）不记在这里：没了结的事另有地方记。每年都会再来的日子（生日、纪念日）要记，日期照他说的写。
- diary：只在记录前那一行说了写今天的日记时才写，说了不写就不要这一项。用她自己的口吻、第一人称，写今天的日记，40 到 120 字：只写记录里真实发生的事，不编、不抒情、不总结人生；没发生什么就写没发生什么。只写正文，不要标题、不要引号。
- 日期：记录里的"（=07-15）"是程序按那句话说的日子算好的，可以照抄；别自己推算"下周三""月底"是哪天。
- 只用记录里有的，不要猜，不新编、不补；名字和具体的说法照原来的字写。没有可写的就给空数组。寒暄、语气词、系统和工具的事一律不记。
- 密码和 API key / token / 密钥一律不记，哪一栏都不行，日记里也不写（写了也会被丢掉）；账号本身、手机号这些可以记。
