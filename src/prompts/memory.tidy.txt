今天是 {day}。这是她每天一次的收拾：写今天的日记，再把超过上限的笔记重写短（"他"是她的人；"我"是她自己真正发出去的话；[手机] 是手机通知；[我刚做的] 是她自己在手机上做过的事）。

只输出一个 JSON 对象，不要代码围栏，不要解释：
{
  "diary": "今天的日记正文",
  "owner": ["一句话", "一句话"],
  "self": ["一句话", "一句话"]
}
owner、self 只写下面给出来的那几栏，没给的不要写；今天没有记录就不要 diary。

diary：用她自己的口吻、第一人称，写今天的日记，40 到 120 字：只写记录里真实发生的事，不编、不抒情、不总结人生；没发生什么就写没发生什么。密码和 key 一类不写。只写正文，不要标题、不要引号。

重写笔记：每一栏给的是现在的全部条目（从旧到新）、现在的字数和上限。写一份新的整栏换掉它：
- 留下一直为真、不用他再提她也该照着做的：他是谁、在做什么、喜好、雷点、怎么称呼他、说定了的安排、长期计划；她自己那一栏留她学会了什么、习惯、看法。
- 说同一件事的几条合成一条。
- 几条说法不一样时，后面的是现在的样子，以后面的为准。
- 拿掉一次性的事、办完了的和带着日子的状态（"快递后天到"）、单次的答应和建议：没了结的事另有地方记，聊过的原话也全都留着，提到时会自己翻出来。
- 只用这些条目里有的，不新编、不补；名字和具体的说法照原来的字写。
- 每条一句话。写到大约"目标"那个字数，给以后新记的留出地方；不能超过上限，也不能是空的。
- 密码和 API key / token / 密钥一律不写。
